# Population test of the ABCC candidate

Analysis in progress, started 2026-09-05. No population genotype result is
claimed at this stage.

The test uses the 29 laboriosa and 28 dorsata worker libraries deposited in
PRJNA931733. Its primary targets are laboriosa protein positions 254, 549 and
1134 in OG0000499 / XP_043798878.1. The prior candidate report is in
[`candidate_followup/REPORT.md`](../candidate_followup/REPORT.md).

Read [`ANALYSIS_PLAN.md`](ANALYSIS_PLAN.md) for the hypotheses, sampling unit,
capture design, genotype criteria and limitations. Source metadata, codon
coordinates and capture controls are generated by the scripts. Complete
paired FASTQs are checked against their original sizes and MD5 values before
candidate-read extraction. The collection workflow saves those evidence reads
with their base qualities and both mates.

The full download is approximately 270 GB compressed. The eventual routine
reproduction will use a preserved, much smaller candidate-evidence archive.
The complete-file collection stage remains separately runnable for verification.

This analysis was developed with Codex. It reuses published sequencing data;
no laboratory experiment is performed.
